# Portafolio profesional

Sitio estático listo para publicar en GitHub Pages. Abre `index.html` en tu navegador para verlo localmente.

## Personalización

1. En `script.js`, añade tu número de WhatsApp a `whatsappNumber`, incluyendo el código de país y sin espacios ni símbolos. Por ejemplo: `const whatsappNumber = '573001234567';`. Hasta entonces, el botón permanecerá desactivado.
2. Edita `index.html` para añadir tu nombre, enlaces, proyectos y cualquier otra información que quieras compartir.
3. Modifica `styles.css` si deseas cambiar los colores o el diseño.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube estos archivos a la raíz.
2. En el repositorio, ve a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**; selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. Espera unos minutos y visita la dirección que aparece en la sección **Pages**. Normalmente será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

Si el repositorio se llama `TU-USUARIO.github.io`, la dirección será `https://TU-USUARIO.github.io/`.
